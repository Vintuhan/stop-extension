# Стоп: блокировщик казино и ставок (версия 0.2)

Расширение для Chrome, Edge, Opera, Яндекс Браузера и Firefox. При заходе на сайт казино, букмекера или кейс-сайта вместо него открывается страница «Стоп».

## Как установить для проверки

**Chrome, Edge, Opera, Яндекс Браузер**
1. Распакуйте архив в постоянную папку (не удаляйте её потом).
2. Откройте `chrome://extensions` (в Edge `edge://extensions`, в Яндексе `browser://extensions`).
3. Включите «Режим разработчика».
4. Нажмите «Загрузить распакованное» и выберите папку `stop-extension` (ту, где лежит `manifest.json`).

**Firefox**
1. В папке расширения переименуйте `manifest.json` в `manifest.chrome.json`, а `manifest.firefox.json` в `manifest.json`.
2. Откройте `about:debugging#/runtime/this-firefox`, нажмите «Загрузить временное дополнение» и выберите `manifest.json`.
3. В `about:addons` откройте расширение, вкладка «Разрешения», и включите доступ ко всем сайтам.
Временное дополнение пропадёт после перезапуска Firefox. Для постоянной установки нужна публикация на addons.mozilla.org.

**Режим инкогнито.** По умолчанию расширения там не работают. В настройках расширения включите «Разрешить в режиме инкогнито».

## Как проверить, что работает

Откройте любой сайт из списка, например `bet365.com`. Вместо него должна появиться страница «Стоп». Безопасный способ: добавьте `example.com` в `tools/seed_domains.txt`, запустите `python3 tools/update_blocklist.py`, нажмите «Обновить» у расширения и откройте example.com. Потом уберите строку.

## Как обновлять список

Файлы, которые вы правите руками (все в папке `tools`, обычные текстовые):
- `seed_domains.txt`: домены, которые точно нужно блокировать;
- `keywords.txt`: слова для «зеркал» (любой адрес с таким словом блокируется);
- `allowlist.txt`: сайты, которые не блокируются никогда (если что-то заблокировалось по ошибке).

Команда `python3 tools/update_blocklist.py` собирает `blocklist.json` заново из ваших файлов и двух открытых списков, которые обновляются сами (Block List Project и HaGeZi). Домены, которые встречаются в обоих списках, идут первыми.
О лицензии: HaGeZi распространяется под GPL-3.0. Если публикуете репозиторий, выберите ему лицензию GPL-3.0 либо поставьте `USE_HAGEZI = False` в начале `update_blocklist.py`.

### Автоматически каждый день (бесплатно, через GitHub)
1. Создайте аккаунт на github.com и **публичный** репозиторий. Загрузите в него всё содержимое папки `stop-extension` (включая скрытую папку `.github`).
2. Откройте файл `blocklist.json` в репозитории, нажмите Raw и скопируйте адрес страницы. Вставьте его в `REMOTE_URL` в файле `background.js`. Расширение будет само подтягивать список раз в 6 часов.
3. Вкладка Actions → включите workflow «Обновление списка». Он запускается каждый день сам, пересобирает список и сохраняет его в репозиторий. Запустить вручную можно кнопкой Run workflow.

### Нейросеть (необязательно)
Нейросеть не ищет зеркала: она не знает, какие адреса появились сегодня, и может выдумать несуществующие. Её роль: проверить домены, в которых вы не уверены.
1. Впишите такие домены в `tools/candidates.txt`.
2. Запустите `python3 tools/classify_domains.py` с ключом `OPENAI_API_KEY` (или добавьте ключ в GitHub: Settings → Secrets and variables → Actions → New repository secret с именем `OPENAI_API_KEY`).
3. В список автоматически попадают только домены с вердиктом «азартные» и уверенностью от 0.9. Остальные вердикты лежат в `tools/llm_results.json`, посмотрите их сами.
Расход мизерный: одна проверка это примерно 500 токенов, при цене недорогой модели около сотой доли цента. Всё равно поставьте лимит расходов в настройках OpenAI, а `MAX_PER_RUN` (по умолчанию 100 доменов за запуск) ограничивает запуск.

### Как находить новые бренды
`python3 tools/suggest_keywords.py` печатает слова, которые чаще всего встречаются в адресах из открытых списков. Выберите из них названия брендов и добавьте в `keywords.txt`. Общие слова (online, bonus, slots) добавлять нельзя.

## Что важно знать

- Блокируется вход на сайт. Уже открытая вкладка с казино не закроется, пока её не перезагрузят.
- Ключевые слова работают по подстроке в адресе, в том числе общее слово `casino`. Если найдёте случайно заблокированный обычный сайт, добавьте его в `allowlist.txt` или уберите слово из `keywords.txt`.
- Пользователь с правами администратора может отключить расширение. Защита от удаления (политика в реестре Windows) делается отдельным шагом, после публикации в Chrome Web Store.
